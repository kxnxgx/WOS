# WOS アイテム集約ツール — 実装完了確認 (Phase 1)

## 実装内容
事前に承認された `implementation_plan.md` に基づき、売上データと在庫データからWOS（Weeks of Supply）を算出し、店舗間のアイテム移動推奨リストを生成する「WOS アイテム集約ツール」の Phase 1 の実装を完了しました。

### 作成したファイルと機能

- `src/data_loader.py`
  - 売上データ（`営業日付別売上分析(旧).csv`）および在庫データ（`在庫一覧.csv`）をShift-JISエンコーディングで安全に読み込みます。
  - 列名揺れに対応するため、特定の列インデックスを基準に必要なデータを抽出するように実装しました。

- `src/wos_calculator.py`
  - 最新の売上日付から過去4週間分のデータを集計し、SKU・店舗ごとの平均販売数を算出します。
  - 在庫データと結合し、`現在在庫 ÷ 4週平均販売数` によってWOSを計算します。販売数がない場合はエラー回避のため計算結果を空として扱います。

- `src/item_allocator.py`
  - SKUごとに全店舗の平均WOSを算出します。
  - 平均WOSを基準に、在庫が余っている店舗（出荷側）と在庫が不足している店舗（受入れ側）を判定します。
  - 余剰数と不足数を比較し、最適な移動推奨数を計算し、わかりやすい移動理由テキストも自動生成します。

- `src/reporter.py`
  - 計算結果から「アイテム移動推奨リスト」および「店舗別WOSサマリー」を含む見やすいHTMLレポート（自包含型）を生成します。
  - 同時に、データ分析用途で再利用できるようExcelファイルも出力します。

- `run.py`
  - ツールの実行エントリーポイント。引数からCSVファイルを受け取り（デフォルト値あり）、上記の各モジュールを順次実行してレポートを出力します。

## 実行・テスト結果
実装完了後、実際の提供データを用いて結合テストを行いました。

- **実行コマンド**: `python run.py`
- **結果**: 正常終了
- **出力物**: 
  - `WOS_Report.html` (アイテム集約リストおよびWOSサマリーが含まれるタブ形式のHTML)
  - `WOS_Report.xlsx` (生データとピボットテーブルが含まれるExcelファイル)
- **検証ポイント**: 
  - CSVの読み込みが正常に行われ、Shift-JIS特有の文字化けなどのエラーが発生しないことを確認しました。
  - ゼロ除算エラーの回避ロジックが正常に働き、WOS計算が完了することを確認しました。

以上で、Phase 1（コアパイプライン構築とレポート出力機能）の開発は完了となります。
